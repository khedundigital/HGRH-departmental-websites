# Project instructions

Follow the business workstation instructions supplied by the owner. This repository is an **unofficial hospital information prototype**. Never present it as approved. Publish only `site/` through the Pages workflow. Keep the warning on every public page. No patient collection, live bookings, simulated submissions, medication doses or O&G claims. The owner has authorised showing historical clinic and admissions examples from the earlier prototype; mark each example unverified, avoid presenting it as current directions, and point readers to official channels. A draft isiZulu demonstration is published with a translation-review notice on every route; qualified language and clinical review are required before operational use. Record sources and approvals in `docs/governance/`; keep sensitive evidence outside this public repository. Run `python3 tests/check_site.py`, inspect the actual site, and document results before release. Preserve original source history and never push to the source remote.
