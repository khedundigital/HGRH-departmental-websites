# Project instructions

Follow the business workstation instructions supplied by the owner. This repository is an **unofficial hospital information prototype**. Never present it as approved. Edit only `site/` for public Pages output; the workflow must publish that directory alone. Keep the warning on every public page. No patient collection, live bookings, simulated submissions, unverified operational specifics, medication doses or O&G claims. English is the only displayed language until qualified translation and clinical review. Record sources and approvals in `docs/governance/`; keep sensitive evidence outside this public repository. Run `python3 tests/check_site.py`, inspect the actual site, and document results before release. Preserve original source history and never push to the source remote.
