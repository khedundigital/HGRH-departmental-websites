# Local setup

No installation is required. Open `site/index.html` in a modern browser. For an HTTP preview, run `python3 -m http.server 8000 --directory site` and visit `http://localhost:8000/`. Test with `python3 tests/check_site.py`. The HTTP server is for preview only; hosting and editing require no build step. Do not include `docs/`, legacy root pages or tests in a manual upload.
